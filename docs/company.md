# LOW KEY - Company Context

## Misión

Crear soluciones tecnológicas utilizando software,
inteligencia artificial y automatización.

## Visión

Construir una empresa tecnológica capaz de desarrollar
productos digitales, servicios y herramientas escalables.

## Principios

- Calidad
- Automatización
- Escalabilidad
- Seguridad
- Código limpio
- Reutilización
- Documentación
- Testing

## Modelo de negocio

LOW KEY tendrá varias líneas:

1. Desarrollo de software
2. Aplicaciones web
3. Aplicaciones móviles
4. Automatización
5. Inteligencia artificial
6. Productos digitales
7. Marketing
8. Contenido
9. Esports

## Objetivo inicial

Conseguir los primeros clientes y generar ingresos
suficientes para cubrir las herramientas utilizadas
y reinvertir en LOW KEY.
